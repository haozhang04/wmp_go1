# 网络架构

## World Model（10 Hz）

每 5 个策略控制周期更新一次。

### 输入

- 本体感知 `prop`：33 维
  - 机身角速度：3 维，缩放系数 `0.25`
  - 投影重力：3 维
  - 速度指令：3 维，缩放系数 `[1.0, 1.0, 0.25]`
  - 关节位置偏差：12 维，缩放系数 `1.0`
  - 关节速度：12 维，缩放系数 `0.05`
- 深度图 `image`：`64 × 64 × 1`
  - 深度限制到 `[0, 2] m`
  - 归一化到 `[-0.5, 0.5]`
- 最近 5 个控制步的动作：`5 × 12 = 60` 维
- 上一时刻 RSSM 隐状态
- `is_first`：用于在 episode 开始时重置隐状态

### 输出

RSSM 直接输出 512 维确定性特征：

```text
World Model RSSM → wm_feature（512维）
```

策略侧的 `wm_feature_encoder` 再进行压缩：

```text
512 → 64 → 64 → 32
```

最终提供给 Actor 的 World Model 特征为 32 维。

## Depth Predictor（深度预测网络）

用于为没有真实相机的环境预测深度图。

### 输入

- 前向高度图 `forward_heightmap`：525 维
  - 采样网格为 `21 × 25 = 525` 个高度点
- 本体感知 `prop`：33 维

拼接后的输入维度：

```text
525 + 33 = 558
```

### MLP 编码器

```text
[B, 558]
    ↓ Linear + ELU
[B, 256]
    ↓ Linear + ELU
[B, 128]
    ↓ Linear
[B, 4096]
```

4096 维向量被重塑为二维特征图：

```text
[B, 4096] → [B, 256, 4, 4]
```

### 转置卷积解码器

```text
[B, 256,  4,  4]
    ↓ ConvTranspose2d + LayerNorm + ELU
[B, 128,  8,  8]
    ↓ ConvTranspose2d + LayerNorm + ELU
[B,  64, 16, 16]
    ↓ ConvTranspose2d + LayerNorm + ELU
[B,  32, 32, 32]
    ↓ ConvTranspose2d
[B,   1, 64, 64]
```
```text
预测深度图：[B, 64, 64, 1]
```

输出与真实深度图使用相同约定：深度范围 `[0, 2] m`，归一化范围 `[-0.5, 0.5]`。

## History Encoder（50 Hz）

### 输入

最近 5 帧状态，每帧 42 维：

- 机身角速度：3 维，缩放系数 `0.25`
- 投影重力：3 维
- 关节位置偏差：12 维，缩放系数 `1.0`
- 关节速度：12 维，缩放系数 `0.05`
- 上一动作：12 维

总输入维度：

```text
5 × 42 = 210
```

### 网络与输出

```text
210 → 256 → 128 → 35
```

- 前 32 维：历史运动状态隐特征
- 后 3 维：预测的机身线速度

完整的 35 维输出都会传给 Actor。

## Actor（50 Hz）

### 输入

```text
History Encoder特征 35
+ 当前速度指令        3
+ World Model特征    32
= Actor输入          70维
```

### 网络与输出

```text
70 → 256 → 128 → 64 → 12
```

输出为 12 维关节动作，随后转换为关节位置目标：

```text
q_target = default_q + 0.25 × action
```

## 完整推理流程

```text
prop33 + depth64×64×1 + action60
                  │
                  ▼
          World Model RSSM → 512 → wm_feature_encoder → 32 ┐
                                                            │
最近5帧状态：5×42 → History Encoder → 35 ────────────────────┼→ 拼接70维
                                                            │
当前速度指令3维 ─────────────────────────────────────────────┘
                                                            │
                                                            ▼
                                                     Actor MLP
                                                            │
                                                            ▼
                                                       12维动作
                                                            │
                                                            ▼
                                                    关节位置目标/PD控制
```
